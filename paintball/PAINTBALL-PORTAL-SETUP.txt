MXS PAINTBALL — CLOUDFLARE PLAYER PORTAL SETUP
================================================

The website, private API, player check-in, organizer dashboard, and random team
generator are built. Complete these Cloudflare and Discord steps once.

IMPORTANT DEPLOYMENT REQUIREMENT
--------------------------------
The Pages project must deploy from this GitHub repository or through Wrangler.
Cloudflare dashboard Direct Upload does not support Pages Functions.

1. CREATE THE D1 DATABASE
-------------------------
1. Sign in to Cloudflare.
2. Open Storage & Databases > D1 SQL Database.
3. Create a database named: mxs-paintball
4. Open its Console.
5. Copy and run the complete contents of /paintball/d1-schema.sql.

2. CONNECT D1 TO THE EXISTING PAGES PROJECT
--------------------------------------------
1. Open Workers & Pages and select the MotoXsyndicate Pages project.
2. Open Settings > Bindings.
3. Add a D1 database binding.
4. Variable name must be exactly: PAINTBALL_DB
5. Select the mxs-paintball database.
6. Save and redeploy the Pages project.

Add the binding to both Production and Preview if the portal will be tested on
Cloudflare preview deployments. Preview may use a separate test D1 database.

3. CREATE THE DISCORD APPLICATION
---------------------------------
1. Open https://discord.com/developers/applications
2. Create a New Application named MXS Paintball.
3. Open OAuth2.
4. Add this Redirect URL:
   https://www.motoxsyndicate.com/api/paintball/auth/callback
5. Copy the Client ID and Client Secret.

4. ADD ENCRYPTED CLOUDFLARE SECRETS
-----------------------------------
1. Open the MotoXsyndicate Pages project.
2. Open Settings > Variables and Secrets.
3. Add DISCORD_CLIENT_ID with the Discord Client ID.
4. Add DISCORD_CLIENT_SECRET with the Discord Client Secret.
5. Encrypt the Client Secret.
6. Save and redeploy the Pages project.

Add matching values to Preview only if Discord has the exact preview callback
URL added to its Redirects. Production alone is enough for the live portal.

5. MAKE YOUR ACCOUNT THE FIRST ORGANIZER
----------------------------------------
1. Visit https://www.motoxsyndicate.com/paintball/register/
2. Sign in once with your Discord account.
3. In Cloudflare, open the mxs-paintball D1 database and browse pb_users.
4. Copy the id value from your user row.
5. Open the D1 Console and run, replacing YOUR_USER_ID:

   INSERT INTO pb_admins (user_id) VALUES ('YOUR_USER_ID');

6. Open https://www.motoxsyndicate.com/paintball/admin/

PLAYER FLOW
-----------
1. Player selects Continue with Discord.
2. Player enters an in-game name and accepts the rulebook once.
3. During the event's displayed check-in window, the player returns to the
   Player Portal and selects Check in for this night.
4. Staff closes check-in and generates random teams.
5. Staff reviews or rerolls the teams and publishes them.
6. Each player sees their team assignment in the player portal.

ORGANIZER FLOW
--------------
1. Create the pickup night in /paintball/admin/.
2. Open check-in.
3. Close check-in at the deadline.
4. Choose 4v4 or 5v5 from the team-size control.
5. Select Generate Teams. Change the format and regenerate if necessary.
6. Select Review Teams, then Create Tournament Bracket after the teams are final.
7. Select Publish Teams so players can see assignments and the public schedule.
8. Enter each score; winners and losing teams advance to the correct matches.
9. Complete the championship and placement matches to rank every team.

The tournament tool adapts to the generated team count. Two, four, or eight
teams use a full placement bracket. Other team counts use a round robin so
every team can be ranked. An odd number of teams receives one rotating bye
per round. Round-robin ties are broken by wins, score differential, points
scored, then team number.

Players beyond the last complete team become rotating reserves.
At least eight checked-in players are required for 4v4 and ten for 5v5.

SECURITY NOTES
--------------
- The Discord Client Secret exists only inside encrypted Cloudflare settings.
- Login sessions are random tokens; only SHA-256 hashes are stored in D1.
- Organizer routes verify the signed-in account against pb_admins.
- Normal players cannot create events, generate teams, or publish assignments.
- _routes.json limits Pages Functions to /api/paintball/* so normal static page
  requests do not consume the Workers request allowance.

BRACKET UPGRADE FOR AN EXISTING DATABASE
----------------------------------------
If the original seven-table schema was already installed, run the complete
contents of /paintball/d1-bracket-migration.sql in the D1 Console once before
deploying the bracket-enabled website. This adds pb_bracket_matches and
pb_placements without changing existing players, events, or registrations.
